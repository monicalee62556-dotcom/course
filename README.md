页面无第三方运行依赖，不需要数据库、账号或外部题库请求。GitHub Pages直接发布仓库根目录 `index.html`。直接下载该文件也可离线学习。

- `source-data.json`：从完整本地原稿保留的52个主题元数据和234道题。
- `lessons.js`：8节先修课与T01～T13。
- `lessons-bearing-gear.js`：T14～T32。
- `lessons-robot-validation.js`：T33～T52。

使用Python 3生成页面：

```sh
python build.py
```

构建会另外生成 `compiled.js`，可用 `node --check compiled.js` 检查语法；发布只需 `index.html`。本地预览可运行 `python -m http.server 8765`。

所有教学算例明确给出假设。效率、配合示例、虚构样本参数不能作为具体型号额定值或生产图样。真实选型应查制造商完整型号、适用标准与试验记录。

### 面试回答顺序

回答结构设计问题时，统一按照“工况定义—方案选择—关键计算—制造装配—试验验证—失效改进”的顺序展开。这样可以把你的现场经验转化为完整的研发闭环，避免只回答某个零件或单个参数。


## 16个专题的面试问法与回答要点

### A01 金属材料与热处理
面试问法：42CrMo为什么要调质？轴类零件表面为什么还要氮化？
回答要点：调质改善心部强韧性，氮化提高表面硬度、耐磨和抗疲劳能力。必须说明材料牌号、热处理状态、硬度范围、变形控制和后续精加工，不能只说“提高强度”。

### A02 铝合金压铸与开模
面试问法：压铸件为什么出现气孔、缩孔和冷隔？结构设计阶段要注意什么？
回答要点：从充型、排气、模温、壁厚变化、浇口和溢流系统分析。设计时检查分型面、拔模斜度、倒扣、滑块、圆角和后加工余量。气密件还要做X射线、CT或气密验证。

### A03 钛合金表面处理
面试问法：钛合金耐腐蚀，为什么还要做表面处理？
回答要点：耐腐蚀不等于耐磨和抗咬合。根据磨损、摩擦、绝缘、外观和温度选择阳极氧化、微弧氧化、PVD或DLC，并检查膜层附着力、厚度、粗糙度和配合尺寸。

### A04 CNC加工与焊接
面试问法：焊接件为什么经常要焊后加工？如何控制焊接变形？
回答要点：焊缝收缩会改变基准、孔距和安装面。通过统一基准、对称焊接、夹具约束、预留加工余量和焊后精加工控制精度，再用三坐标或专用检具确认。

### A05 水下密封与防水结构
面试问法：30米水深设备怎样设计密封？
回答要点：先算压差p=ρgh，再算端盖分离力。区分静密封、旋转密封和电缆密封，校核O形圈压缩率、沟槽、挤出间隙、端盖变形和材料兼容性，最后进行气密定位、水压保压、温循和振动验证。

### A06 公差配合与尺寸链
面试问法：单个零件都合格，为什么装配后仍然卡死？
回答要点：多个尺寸可能同时朝不利方向偏差。先确定功能基准和封闭环，再做极限法或统计法尺寸链分析，同时考虑形位公差、温度、紧固变形和测量误差。

### A07 轴承选型与寿命计算
面试问法：轴承C值、P值和L10寿命分别代表什么？
回答要点：先根据载荷和力臂求支反力，再得到Fr和Fa，按目录系数求P。球轴承L10=(C/P)^3×10^6转，之后换算小时，并继续校核静载、润滑、污染、配合、游隙和预紧。

### A08 齿轮与减速器设计
面试问法：输入10N·m、1500转/分、减速比50、效率0.8，输出是多少？
回答要点：输出转速30转/分，输出扭矩约400N·m，输出功率约1.26kW。继续说明模数、齿数、中心距、齿根弯曲、齿面接触、回差、润滑、温升和峰值扭矩校核。

### A09 机器人关节模组
面试问法：机器人关节除了电机和减速器还需要什么？
回答要点：还需要输出支承、编码器、制动器、壳体、密封、线束和热管理。用末端载荷、连杆自重、姿态和加速度反推连续扭矩、峰值扭矩、倾覆力矩、法兰挠度和回差。

### A10 电机与功率匹配
面试问法：电机功率怎样从负载计算出来？
回答要点：先得到负载扭矩和转速，机械功率P=Tω，考虑减速器和驱动效率。分别检查启动、加速、连续运行、制动回馈和热负荷，不能只按额定功率一个数选型。

### A11 结构轻量化设计
面试问法：减重后强度够，但为什么仍然不能用？
回答要点：还可能刚度不足、屈曲、模态频率下降、连接处失效或载荷引入区被削弱。先找载荷路径，再保留安装面、支承区和受力筋板，比较质量、位移、应力、屈曲和固有频率。

### A12 热管理与散热
面试问法：电机和驱动器发热怎样解决？
回答要点：先分解铜损、铁损、驱动损耗，再画热流路径。用温升=损耗×总热阻估算，检查导热界面、壳体、散热片、风冷或液冷，并用绕组、壳体和环境温度实测验证。

### A13 有限元仿真与多物理场
面试问法：怎样判断有限元结果可信？
回答要点：确认材料、接触、约束和载荷符合实际，检查反力平衡，做关键区域网格敏感性分析，并与梁公式、手算或试验数据对照。尖角应力奇异点不能直接作为设计结论。

### A14 可靠性与疲劳设计
面试问法：零件应力没有超过屈服强度，为什么仍然会断？
回答要点：循环载荷会导致疲劳。要计算应力幅、平均应力和循环次数，检查缺口、焊趾、表面粗糙度和残余应力，再按材料或接头适用的S-N曲线做寿命评估和耐久试验。

### A15 DFM与产品量产
面试问法：你做过样机，怎样把它转成量产产品？
回答要点：从样机问题记录开始，做DFM、DFA、工艺评审、关键特性定义、工装检具、试制验证、过程能力和变更管理。要讲清楚如何减少修配、返工和现场补救。

### A16 BOM成本与供应链
面试问法：怎样判断一个结构方案成本是否合理？
回答要点：拆分材料、外购件、加工、装配、检验、模具、运输、良率和售后成本。比较方案时统一产量和质量要求，用单位良品成本判断，不能只比较供应商报价。

## 面试统一回答模板

遇到任何结构或机械研发问题，都按以下顺序回答：先定义工况和目标，再提出两到三个方案，说明选择依据；接着给出关键公式或校核项目；然后说明制造、装配和成本影响；最后说明试验验证、失效风险和改进方法。这个结构可以把你已有的现场经验转化为完整的产品研发经验。
